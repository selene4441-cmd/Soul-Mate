# 同频 · 交互 Demo

这是一个纯前端交互原型，用于检查关系匹配产品的整体界面和操作流程。

## 运行

无需安装依赖，可以直接打开 `index.html`。更推荐使用本地静态服务器：

```powershell
python -m http.server 8000 --directory demo
```

然后访问：`http://localhost:8000`

## 覆盖流程

1. 欢迎页与价值主张
2. 基础条件和关系目标
3. 5 个高信息增益的取舍问题
4. 可修正的偏好洞察
5. 模拟匹配过程
6. 带概率、置信度和解释的推荐结果
7. 推荐依据与数据来源
8. 双向邀请和模拟聊天
9. 体验反馈与结果标签

## 演示边界

- 所有数据和人物均为本地模拟。
- 不连接后端，不发送网络请求，不保存用户输入。
- 匹配分仅用于展示交互，真实产品必须使用经过校准的结果标签。
- 页面和逻辑可以独立打开，方便后续替换成真实前端组件。
